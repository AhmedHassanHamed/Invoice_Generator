# Pro Invoice Generator

نظام فواتير احترافي متكامل، مبني بالكامل بـ HTML/CSS/JavaScript من غير أي مكتبات ثقيلة أو Backend.

🔗 **جرب النسخة الحية:** https://ahmedhassanhamed.github.io/Invoice_Generator/
## المميزات
- إدارة بيانات الشركة + رفع لوجو
- إضافة عناصر لا نهائية مع حساب فوري
- خصم، ضريبة، وحاسبة عربون (Deposit)
- دعم عملات متعددة (USD, EGP, SAR, EUR)
- وضع ليلي/نهاري + تخصيص لون الهوية بالكامل
- دعم لغتين (عربي RTL / إنجليزي LTR)
- إكمال تلقائي لبيانات العملاء المتكررين
- تصدير PDF وصورة PNG، طباعة مباشرة، ومشاركة واتساب
- سجل فواتير مع بحث فوري + نسخ احتياطي كامل (Export/Import)

## التقنيات المستخدمة
HTML5, CSS3, JavaScript (Vanilla), html2pdf.js, html2canvas
